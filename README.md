# 🌱 나의 첫 commit을 남긴다면?

IT 창업가 5기 스프린터들의 **중간 체크인 이벤트** 저장소입니다.
터미널 없이, **웹 화면 클릭만으로** 참여할 수 있어요. Git/GitHub이 처음이어도 전혀 걱정 없습니다 😊

---

## 📅 참여 기간

**10/26(월) ~ 11/06(금)**

## 📋 참여 방법 (5단계)

### 1단계. 내 파일 열고 편집 모드 켜기

위의 `sprinters` 폴더를 클릭한 뒤, **본인 이름으로 된 `.md` 파일**을 찾아 클릭하세요. 파일을 연 뒤, 오른쪽 위 ✏️ **연필 아이콘**을 클릭하면 편집 모드가 열려요.

> 내 이름이 없거나 안 보이면 운영진에게 말씀해주세요! GitHub 로그인이 안 되어 있다면 먼저 로그인(또는 회원가입)해주세요.

### 2단계. 내 계정으로 복사본 만들기 (Fork)

**"Fork this repository"** 안내가 뜨면 그대로 진행해주세요. 원본 저장소를 내 계정으로 복사해서, 원본에는 영향 없이 자유롭게 수정할 수 있게 해주는 과정이에요.

### 3단계. 답변 작성하고 저장하기

파일 안의 4가지 질문에 편하게 답을 채워주세요. 완벽하지 않아도 괜찮아요!

1. 지금의 나를 **커밋 메시지**로 표현한다면?
2. 개발 파트를 마쳤을 때의 **나**
3. 내가 **바꿀 수 있는** 걱정
4. 내 힘으로는 **어쩔 수 없는** 걱정

다 작성했다면 오른쪽 위 **Commit changes** 버튼을 클릭하고, 커밋 메시지는 기본값 그대로 두거나 간단히 바꾼 뒤(예: `feat: 김코드 중간점검 작성`) **Propose changes** 버튼을 클릭하세요.

### 4단계. Pull Request 제출하기

**Create pull request** 버튼을 클릭하세요. PR 설명란에 보이는 체크리스트에서, 완료한 항목의 대괄호 사이에 **x**를 입력해주세요 (예: `- [x] 4가지 질문에 모두 답변했어요`). 마지막으로 **Allow edits by maintainers** 체크를 해제한 뒤 **Create pull request** 버튼을 눌러 제출을 완료하세요.

> 단계가 많아 보이지만, 전부 **내 결과물을 GitHub에 기록으로 남기는 과정**이에요. 다음 개인미션에서 다시 만날 테니, 지금 부담 없이 먼저 경험해보는 거예요!

### 5단계. 제출 후, 다른 사람 PR에 놀러 가기

상단의 **Pull requests** 탭에서 다른 스프린터들의 글을 구경하고, **이모지 반응 + 응원 댓글**을 남겨주세요 💌

## ⚠️ 꼭 읽어주세요

- 이 저장소는 **공개(Public) 저장소**로, 누구나 내용을 볼 수 있어요. 연락처 등 개인정보보다는 편하게 공유 가능한 선에서 솔직하게 적어주세요 🙏
- **4가지 질문에 모두 답변**해야 참가상 대상이 됩니다.
- 작성한 PR은 따로 merge(병합)하지 않고 **그대로 열린 상태로 보존**됩니다. 각자의 기록으로 남겨두는 거예요.
- 실수로 다른 사람의 branch나 파일을 수정하게 될 걱정은 안 하셔도 돼요 — 각자 본인 fork 안에서만 작업하는 구조라 원본에는 영향이 없습니다.
