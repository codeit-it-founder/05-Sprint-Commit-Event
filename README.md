## 📋 참여 방법 (5단계)

### 1단계. 내 파일 찾기

위의 `sprinters` 폴더를 클릭한 뒤, **본인 이름으로 된 `.md` 파일**을 찾아 클릭하세요. (예: `sprinters/홍길동.md`, `sprinters/김코딩.md` 등)

> 내 이름이 없거나 안 보이면 운영진에게 말씀해주세요!

### 2단계. 편집 모드 열기

파일을 연 뒤, 오른쪽 위 ✏️ **연필 아이콘(Edit this file)** 을 클릭하세요.

> GitHub 로그인이 되어 있지 않다면, 먼저 로그인(또는 회원가입)해주세요.

### 3단계. 4가지 질문에 답변 작성

파일 안의 4가지 질문에 편하게 답을 채워주세요. 완벽하지 않아도 괜찮아요!

1. 지금의 나를 **커밋 메시지**로 표현한다면?
2. 개발 파트를 마쳤을 때의 **나**
3. 내가 **바꿀 수 있는** 걱정
4. 내 힘으로는 **어쩔 수 없는** 걱정

### 4단계. 변경사항 제안하기 (Propose changes)

화면 아래로 내려가면 **"Propose changes"** 버튼이 있어요. 클릭하면 끝!

- 커밋 메시지는 기본값 그대로 두거나, 간단히 바꿔도 좋아요 (예: `feat: 김코드 중간점검 작성`)
- 버튼을 누르는 순간, 내 계정에 복사본(fork)과 변경 내역(branch)이 자동으로 만들어지고 **Pull Request(PR)** 가 생성됩니다.
- 복잡한 용어처럼 보이지만, 사실 **"내가 수정한 내용을 원본에 반영해달라고 제안하는 것"** 뿐이에요. 뒤에서 일어나는 일은 몰라도 전혀 상관없습니다!

### 5단계. 다른 사람 PR에 놀러 가기

상단의 **Pull requests** 탭에서 다른 스프린터들의 글을 구경하고, **이모지 반응 + 응원 댓글**을 남겨주세요 💌

## ⚠️ 꼭 읽어주세요

- 이 저장소는 **공개(Public) 저장소**로, 누구나 내용을 볼 수 있어요. 연락처 등 개인정보보다는 편하게 공유 가능한 선에서 솔직하게 적어주세요 🙏
- **4가지 질문에 모두 답변**해야 참가상 대상이 됩니다.
- 작성한 PR은 따로 merge(병합)하지 않고 **그대로 열린 상태로 보존**됩니다. 각자의 기록으로 남겨두는 거예요.
- 실수로 다른 사람의 branch나 파일을 수정하게 될 걱정은 안 하셔도 돼요 — 각자 본인 fork 안에서만 작업하는 구조라 원본에는 영향이 없습니다.
